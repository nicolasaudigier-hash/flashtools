Guide d'installation — Signature Email
Gmail
Parametres (roue dentee) → Voir tous les parametres → Signature → Creer → Coller le HTML

Outlook
Fichier → Options → Courrier → Signatures → Nouvelle → Coller

Apple Mail
Mail → Preferences → Signatures → + → Coller dans le champ

Astuce
Copiez le HTML avec le bouton, ouvrez votre client email, collez directement dans l'editeur de signature.
